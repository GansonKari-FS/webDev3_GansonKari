# Spotify Music Search

Spotify Music Search is a web application that allows users to search for their favorite artists, albums, and songs. The project includes a frontend interface, an Express backend, and a SQLite database using Sequelize.

## Features

- Spotify-style music search interface
- Express.js backend server
- SQLite database
- Sequelize ORM
- User CRUD operations
- Environment variable support
- Separate frontend and backend structure

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Sequelize
- SQLite
